# Contributing to Chess Daily Trainer

First off, thank you for considering contributing to Chess Daily Trainer! It's people like you that make the open-source community such a great place to learn, inspire, and create.

## How Can I Contribute?

### Reporting Bugs
- Use GitHub Issues to report bugs.
- Provide a clear description and steps to reproduce.

### Suggesting Enhancements
- If you have an idea to make the app better, open an issue first to discuss it.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the test suite passes (`npm run build` and `npm run lint`).
4. Issue that pull request!

## Project Structure
- `chess-app/src/components`: React components (UI).
- `chess-app/src/lib`: Chess logic and puzzle engine.
- `chess-app/src/data`: Puzzle dataset (JSON).
- `chess-app/scripts`: Scripts for generating data.

## Coding Standards
- Follow the existing code style.
- Use TypeScript for all logic.
- Comment complex algorithms or non-obvious UI decisions.
